# AvaDesk — AI Receptionist

A modern AI receptionist and customer lead-management demo designed for small businesses.

## Overview

AvaDesk demonstrates how an AI receptionist can help businesses handle common customer questions, capture leads, support appointment requests, and hand conversations off to a human.

## Features

- Responsive business landing page
- AI receptionist chat simulation
- Business FAQ handling
- Customer name memory
- Appointment and quote request flow
- Human handoff
- WhatsApp lead handoff
- Customer lead capture form
- Admin lead dashboard
- Lead search and status management
- Mobile responsive design

## Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design

## Demo

The project includes:

- Customer-facing website
- AI receptionist interface
- Admin lead dashboard

## Important Note

This is a portfolio/demo project. The current AI conversation engine uses predefined JavaScript responses and the admin dashboard uses browser localStorage.

A production version could connect the interface to a real AI model, CRM, calendar, WhatsApp API, voice agent, or cloud database.
